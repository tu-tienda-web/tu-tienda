# Tienda Online
Este es un proyecto de una tienda online, donde los usuarios pueden ver productos, agregar artículos al carrito y ver un resumen de los artículos que han agregado. El proyecto fue desarrollado con HTML, CSS y una estructura básica para un posible desarrollo en JavaScript.

## Descripción

La página está estructurada con las siguientes secciones principales:

- *Cabecera*: Contiene el título de la tienda y una breve descripción que da la bienvenida a los usuarios.
- *Galería de productos*: Muestra los productos disponibles en la tienda con su imagen, nombre, precio y botones para agregar al carrito o quitar del carrito.
- *Resumen del carrito*: Muestra un resumen de los productos que han sido agregados al carrito.
